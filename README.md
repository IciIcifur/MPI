# Лабораторная работа: Параллельные алгоритмы с использованием MPI

## Описание проекта

Проект содержит реализации трех параллельных алгоритмов с использованием MPI:
1. **Вычисление числа π** методом Монте-Карло
2. **Умножение матрицы на вектор** с различными схемами распределения данных
3. **Матричное умножение по алгоритму Кэннона**

## Структура проекта

```
├── main.c                    # Главная программа
├── tasks/
│   ├── tasks.h              # Заголовочный файл задач
│   ├── pi.c                 # Вычисление π
│   ├── matrix_multiplication.c  # Умножение матрицы на вектор
│   └── cannon.c             # Алгоритм Кэннона
├── scripts/
│   ├── run_benchmark_pi.py      # Бенчмарк для π
│   ├── run_benchmark_matrix.py  # Бенчмарк для матриц
│   ├── run_benchmark_cannon.py  # Бенчмарк для Кэннона
│   ├── analyze_results_pi.py    # Анализ результатов π
│   ├── analyze_results_matrix.py # Анализ матричных результатов
│   └── analyze_results_cannon.py # Анализ результатов Кэннона
├── results/                 # Директория для результатов
├── Makefile                # Сборка проекта
├── CMakeLists.txt          # Альтернативная сборка
├── run.sh                  # Скрипт запуска
└── run_analysis.sh         # Скрипт анализа
```

## Установка зависимостей (Ubuntu)

```bash
sudo apt update
sudo apt install -y mpich python3 python3-pip python3-matplotlib build-essential cmake
pip3 install numpy matplotlib
```

## Компиляция и сборка

### Способ 1: Использование Makefile
```bash
make clean
make
```

### Способ 2: Использование CMake
```bash
mkdir build && cd build
cmake ..
make
```

### Способ 3: Прямая компиляция
```bash
mpicc -o main main.c tasks/*.c -lm
```

## Запуск программ

### Интерактивный режим
```bash
./run.sh
```
Программа предложит выбрать задание:
- `1` - Вычисление π
- `2` - Умножение матрицы на вектор
- `3` - Алгоритм Кэннона

## Автоматический бенчмаркинг и анализ

### Запуск полного анализа
```bash
# Для вычисления π
./run_analysis.sh 1

# Для умножения матрицы на вектор
./run_analysis.sh 2

# Для алгоритма Кэннона
./run_analysis.sh 3
```

### Запуск анализа по готовым csv
```bash
# Анализ по results/pi_results/pi_results.csv
python3 scripts/analyze_results_pi.py

# Анализ по results/matrix_results/matrix_results.csv
python3 scripts/analyze_results_matrix.py

# Анализ по results/cannon_results/cannon_results.csv
python3 scripts/analyze_results_cannon.py
```

## Параметры тестирования

### Задание 1 (π)
- **Итерации**: 1M, 10M, 100M
- **Процессы**: 1, 2, 4, 8
- **Алгоритмы**: NAIVE, MANUAL, GATHER

### Задание 2 (Матрица-вектор)
- **Размеры матриц**: 500-20000 с шагом 500
- **Процессы**: 1, 2, 4, 8
- **Схемы распределения**: ROW, COLUMN, BLOCK

### Задание 3 (Алгоритм Кэннона)
- **Размеры матриц**: 64-2048 (15 размеров)
- **Процессы**: 1, 4, 9, 16 (только квадраты)
- **Итерации**: 3 повторения для усреднения

## Результаты

После выполнения анализа результаты сохраняются в директории `results/`:
- `pi_results/` - графики и статистика для π
- `matrix_results/` - результаты матричных операций
- `cannon_results/` - результаты алгоритма Кэннона

**Генерируемые графики:**
- Время выполнения vs размер задачи
- Ускорение vs количество процессов
- Эффективность vs количество процессов
- Сравнение алгоритмов
